Password Managers

Remembering dozens of strong passwords is unrealistic, which is why most people reuse a handful of them. A password manager stores them instead, so that every account can have a long and unique password.

How a password manager works

The vault

All credentials are stored in an encrypted database known as the vault. It can remain on a single device or be synchronized across computer and phone.

The master password

A single password unlocks the vault, and it is the only one the user still has to remember. It should be long and never reused elsewhere.

The generator

For each new account the manager generates a random password such as "tR7#qL2!vX9p". Nothing a person invents is as hard to guess.

Why it matters

When a website is breached, attackers test the stolen email and password pairs on other services, a technique known as credential stuffing. It succeeds only because passwords are reused. With a different password for every account, the damage is confined to the service that was breached.

Built-in or dedicated?

Types of password managers
Type Examples Pros Cons
Built-in Apple Passwords, Google Password Manager Free and already installed Largely tied to a single ecosystem
Dedicated Bitwarden, 1Password Works on every device and browser One more account to secure, and some require a subscription
Offline KeePassXC The vault never leaves your computer Synchronization and backups are left to the user

When things go wrong: the LastPass breach

2022

In 2022 attackers breached LastPass and copied backups of customer vaults. The vaults were encrypted, so opening one still required guessing its master password. Users with a weak master password were the most exposed.

How to use one safely

  • Master password: choose a long passphrase built from unrelated words.
  • Two-factor authentication: enable it on the manager itself.
  • Updates: keep both the application and your devices up to date.
  • Recovery: keep a written copy of the master password in a safe place, because the provider cannot reset it.
