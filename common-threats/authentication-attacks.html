Authentication Attacks

Many attackers do not break into a system with a complex exploit: they simply log in with a correct password. This page compares three ways to find one: brute force, credential stuffing and password spraying.

Brute force

The attacker chooses one account and tries many passwords until one works. Often they use lists of common passwords instead of every possible combination. Because one account receives many wrong attempts, this attack is easy to notice and to block.

Credential stuffing

When a website is hacked, the emails and passwords of its users are often published online. In credential stuffing the attacker takes these pairs and tries them on other websites. It works because many people use the same password on more than one site.

Each pair is tried only once, so there are no repeated failures on the same account. The attack is done by bots, often from many different IP addresses.

Password spraying

Password spraying is the opposite of brute force. The attacker tries a few very common passwords (for example Password123) on many accounts. After one try on every account, the attacker waits and then tries the next password.

Each account gets only one or two wrong attempts, so it is not locked. This attack is often used against companies and schools, where usernames are easy to guess (for example name.surname@company.com).

Real example: in 2024 Microsoft announced that the hacker group Midnight Blizzard used password spraying to enter an old test account that did not have multi-factor authentication. From there they read the emails of some employees.

Comparison

The three attacks compared
Attack Accounts Passwords per account Why it works
Brute force One Many Short or weak passwords
Credential stuffing Many One (the leaked one) The same password is reused
Password spraying Many A few common ones Some people use popular passwords

How to defend

  • Use multi-factor authentication (MFA): a stolen password is not enough anymore.
  • Use a different password for every website, for example with a password manager.
  • Websites should limit the number of failed logins and add delays after wrong attempts.
  • Websites should refuse passwords that appear in lists of leaked passwords.
  • Companies should watch for one password failing on many different accounts, a sign of spraying.
