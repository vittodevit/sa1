\subsection{Overall team leadership and coordination}
\label{sec:leadership}

The project was coordinated by Angelica and Vittorio, who shared leadership responsibilities while focusing on different areas.

\paragraph{Angelica -- Team coordination}

Angelica focused on the organization and coordination of the team. Her work included setting deadlines, providing feedback, collecting opinions from members, and helping maintain communication between the different groups.
She also assisted members when they encountered issues with HTML documents or needed clarification about the project requirements, and prepare documentation.

An important part of this role was following the progress of the different groups, identifying problems that could affect the overall project, and helping members understand what needed to be corrected or completed.

\paragraph{Vittorio -- Git management and technical integration}

Vittorio took primary responsibility for the Git workflow and the technical integration of the website. He independently managed the repository workflow, handled merge conflicts, and resolved many of the technical issues encountered
during development.

He also dedicated considerable time to checking the appearance and functionality of the HTML pages and correcting problems so that the different contributions could work together within the same website. In addition, he prepared detailed Git documentation and helped members understand how to work with the repository.

\subsection{Collaboration and communication}
\label{sec:collaboration}

Communication between the different groups was essential for coordinating work and integrating their contributions.

While some members regularly shared feedback and communicated difficulties, others were occasionally unresponsive in group chats. This sometimes resulted in requested HTML modifications being overlooked despite reminders, requiring the team leaders to implement the corrections themselves.

Topic leaders also helped coordinate members, clarify assignments, collect contributions, follow up on modifications, and ensure their sections were complete.

\subsection{Website consistency and corrections}
\label{sec:corrections}

One of the main challenges was maintaining consistent layouts and structures across all article pages.

The CSS leaders provided a shared template, but some members did not follow it consistently,
resulting in different layouts across the website.

Consequently, several pages required corrections to ensure consistent structure, appearance, and functionality.
Other issues, including incorrect HTML structure, CSS links, and navigation, also needed attention.

These corrections required cooperation between team leaders, CSS leaders, and the members responsible for the pages,
highlighting the importance of following shared guidelines when developing a website collaboratively.
