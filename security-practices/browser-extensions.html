Browser extension permissions

Extensions add features to your browser, but they also receive access to parts of your browsing. Keep the useful tools and question the permissions they request.

Review the access you give to browser extensions.

Read the permission, not just the name

A useful-sounding extension can still request more access than you expect. Compare its stated purpose with the permissions shown before installation.

Questions to ask about an extension
Requested access What to consider
Read and change website data It may inspect or modify content on the permitted sites. Does it need every site, or just the site where you use it?
Bookmarks It may read and reorganise saved links. Is that necessary for its job?
Browsing history This can reveal sites you have visited. Decide whether the feature is worth granting that access.

When installing

  • Use the browser's official extension store and check the publisher.
  • Read the permission request. A high rating is not a guarantee of safety.
  • Cancel if the requested access does not make sense for the feature.

During a clean-up

  • Open the browser's extension manager and review what is installed.
  • Remove extensions you no longer need.
  • Where supported, limit website access to specific sites or activation on demand.

Example: a tool for one website

You install a helper for a single study website. If the browser offers a site-access control, restrict it to that website instead of granting access across all browsing. Test the feature afterwards: restricting permissions may stop some functions from working.

Does HTTPS make an extension harmless?

No. HTTPS protects the connection. An extension with permission to access a page may still read its content inside the browser. See HTTPS and TLS for the connection side.

Sources

These examples use Chrome. Other browsers and managed school devices may expose different controls.
