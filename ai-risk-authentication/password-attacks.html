Attacks Against Password-Based Authentication

When you log in with a password, you enter your username and password. The service checks whether they match an account. If they do, it lets you in. Attackers want passwords because a stolen password can give them access to someone’s accounts, private information, or money. They may also try the same password on other services. On this page, you’ll learn about brute-force attacks, dictionary attacks, and credential stuffing and how websites stop them.

Brute-force attacks

A brute-force attack tries every possible password combination until one works. Each extra character multiplies the number of possible combinations, making a longer, randomly chosen password much harder to guess.

Password length and combinations
Password Possible combinations
4-digit PIN 10.000
8 lowercase letters about 209 billion
12 lowercase letters about 95 quadrillion

Dictionary attacks

Instead of trying every possible combination, a dictionary attack tries passwords people are likely to choose, such as common passwords, words, names, and passwords from earlier leaks. Predictable “clever” changes like replacing a letter with a symbol or adding a number are easy for attackers to try automatically.

Examples of passwords that look clever but aren't:

  • P@ssw0rd
  • IloveBaklava123
  • Hacker123!

Real example: RockYou (2009)

In 2009, hackers exposed about 32 million RockYou passwords that had been stored in plain text. Password lists from data breaches like this are still used to study and guess passwords.

Credential stuffing

Attackers take username and password pairs leaked from one website and try them on other websites. It works when people reuse the same password across multiple accounts.

How it works:

  1. Step 1

    A website gets hacked.

  2. Step 2

    A list of usernames and passwords leaks.

  3. Step 3

    A program tries those login details on other websites.

  4. Step 4

    Accounts using the same password may be opened.

Learn more about Passwords and Passphrases, or check whether your email appears in known data breaches.

Real example: 23andMe (2023)

Attackers used reused passwords to access about 14.000 23andMe accounts. Through the DNA Relatives feature, they were able to access profile information linked to about 6.9 million people.
