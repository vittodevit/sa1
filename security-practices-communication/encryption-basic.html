Encryption basics

Encryption turns a readable message into unreadable symbols, which only a person with the correct key can understand.

Encryption protects information by turning readable data into unreadable ciphertext.

How encryption works

Plaintext - Encryption + Key - Ciphertext

Ciphertext - Description + Key - Plaintext

Two types of encryption

Symmetric Asummetric
One shared secret key Public key and private key
Fast Slower
Used for large amounts of data Used for key exchange and signatures

Modern systems comibe both types of encryption. Asymetric cryptography helps establish a shared key, and symmetric encryption helps to protect data.

Mailbox analogy

Any person can put a letter into a mailbox using the public key, but only the owner can open it and read information with the private key.

Quick tips

  • Encryption protects data in transit and storage.
  • Keep private keys actually private
