HTTPS and TLS

The padlock means the connection is private. It doesn't imply that the site is trustful.

HTTPS uses TLS to encrypt communication between a browser and a website.

HTTP vs HTTPS

HTTP HTTPS
Data sent as plain text Data sncrypted with TLS
Network observers can read the data Data is protected between browser and website

What HTTPS means

  • It encrypts the connection.
  • It confirms that the website controls its domain.
  • It does not guarantee that the website is trustful.

https://your-bank.com

https://your-bank.comlogin-check.example

The second website belongs to login-check.example, and not your-bank.com, as it can seem

Useful tips.

  • Never enter passwords on HTTP pages.
  • Do not ignore certificate warnings.
  • Check the domain, not only the padlock
