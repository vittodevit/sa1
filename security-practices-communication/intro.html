Secure Communication

All messages pass through devices that we do not control, for instance routers, internet providers and servers. Secure communication helps keep our information safe from any changes and being read by others.

How a message travels

Phone - Router - Provider - Server - Friend

Encryption helps protect the message on its journey.

Three goals of secure communication

Goals Meaning Example
Confidintiality Only the receiver can read it A private chat
Integrity Nothing changed on the way Bank transfer amount stays the same
Authenticity It really comes from the sender A message really from your bank
