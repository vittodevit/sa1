Data and Model Poisoning

AI systems depend on the data used to train them. Attackers can target that data or change the model itself to make it give wrong results.

What is data poisoning?

Data poisoning means deliberately changing data used to train or update an AI system so that it learns the wrong patterns.

For example, an attacker could mark spam messages as safe in a training dataset. A spam filter trained on that data might then miss harmful messages.

What is model poisoning?

Model poisoning involves changing a model or its updates so that it behaves incorrectly.

A poisoned model may work normally for most inputs but give a wrong result when it sees a particular word or pattern. This hidden behaviour is called a backdoor.

How can we reduce the risk?

  • Use data from trusted sources.
  • Check datasets for unusual or incorrect examples.
  • Test the model before using it for important tasks.
